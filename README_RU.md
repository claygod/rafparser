# rafparser

Высокопроизводительный парсер и конвертер RAW-файлов Fujifilm (.RAF) на Go с поддержкой аппаратного пиксельного биннинга и экспорта в профессиональный HDR-формат OpenEXR.

Основная философия утилиты — **получение максимально честной, эластичной и несжатой цветовой информации** напрямую с сенсоров Fujifilm (X-Trans и Bayer) без интерполяционных артефактов дебайеризации.

## ✨ Особенности и возможности

* **Чистый Pure Color:** Доступ к исходным линейным координатам матрицы без принудительного запекания гамма-кривых.
* **Аппаратный биннинг (2x2):** Объединение триплетов пикселей на физическом уровне для достижения беспрецедентного микроконтраста и полного отсутствия цветового шума.
* **HDR Экспорт в OpenEXR (.exr):** Запись данных в формате 16-бит с плавающей запятой (Half Float) с PIZ-сжатием без потерь. Никакого искусственного клиппинга — детали в пересветах сохраняются со значениями `> 1.0` и легко восстанавливаются экспозицией в графическом софте.
* **Умный интерфейс CLI:** Оптимизирован под удобную интеграцию в IDE. Корректно обрабатывает пути и слэши как в Linux/macOS, так и в Windows.

## ⚠️ Важное предупреждение (Экспериментальные функции)

Функции технической мозаики (`-mosaic`), создания цифрового негатива (`-dng`) и двухпроходного восстановления светов (`-recovery`) на данный момент **абсолютно нестабильны**. Работа над ними только началась. Сейчас они добавлены исключительно для справки и ознакомления, но **не для практического использования** в продакшн-пайплайне. Стабильными и готовыми к работе являются модули `-exr`, `-tif` и `-preview`.

## 🛠 Требования к сборке

Проект использует CGO-биндинги к библиотеке **LibRaw**. Перед компиляцией убедитесь, что в вашей системе установлены заголовочные файлы LibRaw.

### Установка зависимостей (Ubuntu/Debian):
```bash
sudo apt-get update
sudo apt-get install libraw-dev
```

### Установка зависимостей (macOS / Homebrew):
```bash
brew install libraw
```

## 🚀 Установка и сборка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd rafparser
   ```
2. Скачайте Go-зависимости (модуль Pure Go OpenEXR):
   ```bash
   go get ://github.com
   ```
3. Скомпилируйте утилиту:
   ```bash
   go build -o rafparser
   ```

## 💻 Использование (CLI)

Утилита спроектирована по канонам классического консольного софта Linux. **Путь к исходному RAF-файлу всегда должен идти самым первым аргументом.**

### Команда вызова справки:
```bash
./rafparser --help
```

### Пример базового синтаксиса:
```bash
./rafparser <путь_к_файлу.RAF> [опции] [папка_вывода]
```
*Если папка вывода не указана, все результаты будут сохранены в ту же директорию, где лежит исходный файл.*

### Примеры использования:

1. **Генерация HDR OpenEXR (рекомендуемый стабильный режим):**
   ```bash
   ./rafparser photo.RAF -exr
   ```
   *Создаст файл `photo.RAF.exr` рядом с исходником со стандартным коэффициентом ослабления яркости 3.5 для правильного Tone Mapping в конвертерах.*

2. **Экспорт стабильных форматов одновременно в кастомную папку:**
   ```bash
   ./rafparser photo.RAF -exr -tif -preview /home/user/output_folder
   ```
   *Сгенерирует HDR EXR, стандартный 16-битный линейный TIFF и извлечет встроенное JPEG-превью в указанную директорию.*

## 📋 Доступные опции экспорта

| Флаг | Тип | Описание | Статус |
| :--- | :--- | :--- | :--- |
| `-exr` | bool | Генерировать HDR-файл OpenEXR (`.raf.exr`) | **Стабильно** |
| `-tif` | bool | Генерировать стандартный линейный TIFF кадр (`.raf.tif`) | **Стабильно** |
| `-preview` | bool | Извлечь встроенное в RAW JPEG-превью (`.raf.preview.jpg`) | **Стабильно** |
| `-mosaic` | bool | Генерировать технический TIFF сырой мозаики (`.raf.mosaic.tif`) | *Эксперимент (Нестабильно)* |
| `-dng` | bool | Генерировать цифровой негатив Linear DNG (`.raf.dng`) | *Эксперимент (Нестабильно)* |
| `-recovery` | bool | Включить двухпроходное восстановление экстремальных светов | *Эксперимент (Нестабильно)* |
| `-light` | float | Коэффициент ослабления базовой яркости для EXR (дефолт: `3.5`) | **Стабильно** |
